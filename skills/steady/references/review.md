# Review

Use [review](../../review/SKILL.md) for the specified change or artifact. Establish a concrete baseline and evidence surface. Assess relevant behavior, contracts, and maintainability without editing the subject unless the user also requested fixes.

Distinguish introduced defects from existing issues. Request independent review only when required or justified by consequence and permitted by the host. A second pass by the same agent must not be described as independent.

Completion is the requested coverage and an evidence-backed verdict, including limitations. Finding no issues is not proof of every runtime or deployment condition.

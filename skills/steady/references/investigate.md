# Investigate

Answer the question from relevant source or runtime evidence. Establish whether the user requested explanation, diagnosis, or a read-only audit. Do not implement a fix because the answer makes it obvious.

Trace the path needed to support the claim. Use existing artifacts first. Experiments must fit the authorization; no-write tasks exclude test commands, application launches, or tools that create caches or logs. Separate confirmed causes from plausible explanations.

Use [research](../../research/SKILL.md) for external facts, [debug](../../debug/SKILL.md) for difficult causal diagnosis, or [review](../../review/SKILL.md) for a bounded change assessment when needed. Return the supported answer, evidence, and material unknowns.

# Capture a draft

Read [plan format](../work-plan/references/plan-format.md). Locate the selected work repository. If no location is known, ask for it; do not scatter records among guessed repositories.

Before the first record edit, establish that you are the single coordinator writing this work repository. If another coordinator owns it, return the proposed update to that owner; do not edit a competing copy.

Check relevant drafts and completed plans for duplication. Create a uniquely named draft containing the user's intended outcome, source context, known constraints, and unresolved questions. Preserve uncertainty rather than inventing a cause or design. Collect only inexpensive relevant context; defer substantial investigation to planning.

Update the index under its single writer when an index exists. Leave the draft in `drafts/`. Report its path and any related plan. Do not dispatch, implement, or publish simply because the draft now exists.
